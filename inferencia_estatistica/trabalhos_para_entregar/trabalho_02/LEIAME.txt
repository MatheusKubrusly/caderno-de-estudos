COMO EXECUTAR
1. Instalar as dependências:
       pip install -r requirements.txt
2. Colocar os arquivos de dados na pasta data/ (golfe.csv, mtcars.csv,
   data9.xls e treatment.csv).
3. A partir desta pasta (raiz da entrega), executar cada script:
       python q1_tacos_golfe.py
       python q2_transmissoes.py
       python q3_anova_carros.py
       python q4_anova_custos.py
       python q5_qui_quadrado.py

Os scripts são independentes entre si, não pedem nenhuma entrada e não
acessam a Internet. Cada um cria a pasta resultados/ (se ainda não existir)
e grava nela o JSON e os gráficos PNG da sua questão, além de imprimir um
resumo dos cálculos no terminal. A Q3 usa os dados da Listagem 1 do
enunciado, que estão no próprio script.
